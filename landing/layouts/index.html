01 / FROM EXPECTATION TO EVIDENCE

Declare it.
Check it.

A small configuration says which commands you expect and what version counts as compatible. The audit runs version probes and reports what it can determine.

01

List the commands

Add expected tools to [tool.cli-tools] in pyproject.toml.

02

Probe the environment

Read the tools on PATH and ask each one for a version where possible.

03

Review the result

Spot missing, incompatible, or unparseable version reports before they surprise a workflow.

pyproject.toml
[tool.cli-tools]
python = { version = ">=3.11", schema = "semver" }
make = { version = ">=3.81", schema = "semver" }
rustc = { schema = "existence" }
THEN RUNcli_tool_audit auditConfiguration guide ↗

04 / THE LIMIT

Version output
is not universal.

CLI tools disagree on their version switches and formats. Some checks can only establish existence or compare an exact output snapshot. Review ambiguous results instead of assuming every version can be parsed.
